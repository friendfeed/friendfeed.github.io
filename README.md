# فرندفید فارسی: آرشیو

آرشیو پژوهشی و غیررسمی جامعه فارسی‌زبان فرندفید (۲۰۰۷–۲۰۰۹ / ۱۳۸۶–۱۳۸۸)،
بازسازی‌شده از اسنپ‌شات‌های Wayback Machine و ردیابی‌شده تا حساب‌های فعلی
کاربران در ایکس (X).

بدون وابستگی به فرندفید یا متا. تمام داده‌ها از منابع آرشیوی عمومی
گردآوری شده و هر ادعا سطح اطمینان مشخصی دارد (تأییدشده / احتمالی / حدسی).

## پشته فنی

- React 19 + TypeScript (OOP models در `src/models`, سرویس‌های داده در `src/services`)
- Vite
- `react-router-dom` با `HashRouter` (سازگار با GitHub Pages بدون نیاز به rewrite)
- فونت Vazirmatn، چیدمان کاملاً راست‌به‌چپ
- بدون آیکون فونتی، همه آیکون‌ها SVG درون‌خطی (`src/icons`)

## اجرای محلی

```bash
npm install
npm run dev
```

## بیلد و بررسی نوع

```bash
npx tsc --noEmit
npm run build
```

## استقرار

پوش به شاخه `main` به‌طور خودکار workflow در
`.github/workflows/deploy.yml` را اجرا می‌کند که بیلد را به GitHub Pages
می‌فرستد. در تنظیمات مخزن (Settings → Pages) باید Source روی
"GitHub Actions" تنظیم شود.

## افزودن کاربران جدید

تمام داده‌ها در یک فایل است: `src/data/users.json`. راهنمای کامل ساختار
هر رکورد (اسنپ‌شات‌ها، لینک‌ها، عضویت‌ها، مچ ایکس و سطح اطمینان آن) در
[`docs/DATA_SCHEMA.md`](./docs/DATA_SCHEMA.md) آمده است.

قانون اصلی پروژه: هیچ داده‌ای حدس زده نمی‌شود. اگر چیزی در آرشیو دیده
نشده، در JSON هم نباید ظاهر شود.

## صفحات سایت

| مسیر | محتوا |
|---|---|
| `/` | تقویم کاربران بر اساس سال |
| `/user/:id` | پروفایل کامل یک کاربر |
| `/x-crossover` | کاربرانی که اکنون در ایکس شناسایی شده‌اند |
| `/pyramid` | هرم رتبه‌بندی (قدیمی‌ترین حساب‌ها / بیشترین دنبال‌کننده) |
| `/history` | پیشینه مستند فرندفید + تحلیل ویدیویی (در انتظار رونوشت) |
